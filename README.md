# Base React Three Fiber
Base project made in React Three Fiber. This project contains a simple FPS controller which you can use as a starting project for your game jams.

This project should comply with the Ludum Dare Compo rules, which state: `You’re free to start with any base-code you may have.` 


## How to run
Clone the repository and then install the project by running:

```npm install```

Then you can run it by:

```npm run dev```
